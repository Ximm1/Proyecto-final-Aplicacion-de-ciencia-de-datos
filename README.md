# Poyecto-final-Aplicacion-de-ciencia-de-datos
Analizador de flavonoides es un proyecto final en MIT App Inventor que analiza datos de flavonoides respecto a la cantidad de alcohol y alcalinidad presente en los vinos.  Estos datos provienen del análisis químico de vinos cultivados en una misma región de Italia, pero elaborados a partir de tres variedades de uva diferentes.
