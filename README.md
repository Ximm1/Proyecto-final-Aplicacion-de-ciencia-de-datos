# Proyecto-final-Aplicacion-de-ciencia-de-datos
Analizador de flavonoides, proyecto final en MIT App Inventor analiza datos de flavonoides respecto a la cantidad de alcohol y alcalinidad presente en los vinos. 
Estos datos provienen del análisis químico de vinos cultivados en una misma región de Italia, pero elaborados a partir de tres variedades de uva diferentes.

La base de datos empleada se compone de datos experimentales reales. Todo el contenido es propiedad exclusiva del autor. Reservados todos los derechos.
